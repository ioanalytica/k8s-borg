# Code of conduct

k8s-borg follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
in every space of the project: issues, discussions, pull requests and reviews.

In short: be respectful and constructive, assume good intent, and keep the
discussion about the work. Harassment, personal attacks and discriminatory
language are not tolerated.

## Reporting

Open a
[private report](https://github.com/ioanalytica/k8s-borg/security/advisories/new)
and state that it concerns the code of conduct, with links to the posts in
question; only the maintainers can see it. GitHub's own **Report content** on a
comment, issue or discussion reaches GitHub's staff, not the maintainers.

The maintainers review every report, keep the reporter's identity confidential,
and act as the Contributor Covenant's enforcement guidelines describe.
